Calculator Project Report

Implementation of Modulo (%) and Exponent (^) Functions

Introduction

This project involved improving a simple calculator by adding the modulo (%) and exponent (^) operations using HTML,CSS and JavaScript. These Functions extend the calculator beyond basic arithmetic.

Project Analysis

Modulo Function

The modulo operator (%) returns the remainder after dividing one number by another.

  • 10 % 3 = 1
  • 20 % 4 = 0

Exponent Function

The exponent operator (^) raises a number by the power of another number.

  • 2 ^ 3 = 8
  • 5 ^ 2 = 25

Algorithms

Modulo Algorithms

  1. Start
  2. Read the first number (divicend).
  3. Read the second number (divisor).
  4. If the divisor is negative convert it to a positive number
  5. Store the dividend as the current remainder.
  6. Repeatedly subtract the divisor fromm the remainder while the is greater than or equal to the divisor.
  7. When the remainder becomes smaller than the divisor, stop.
  8. Display the result
  9. Stop

Exponent Algorithms

  1. Start.
  2. Read the base number (num1).
  3. Read the exponent number (num2).
  4. Set the result to 1.
  5. Check if the exponent is equal to 0
  6. If the the exponent is 0, set the result to 1.
  7. Otherwise, repeat the following untill the loop has executed the same number of time as the exponent:
    • Multiply the current result by the base.
  8. Store the result in the answer variable.
  9. Display the answer.
  10. Stop
